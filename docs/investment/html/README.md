# حزمة صحّتك الاستثمارية — ملفات HTML

هذه الحزمة مخصصة للمراجعة الاستثمارية والعناية التقنية الأولية، وهي مستقلة عن فرع الإنتاج.

## الملفات
- `executive-summary.html`: ملخص موجز من 8 صفحات A4 للاجتماع الأول.
- `report-full.html`: تقرير تفصيلي من 18 قسماً للمراجعة الفنية والاستثمارية.

## الفتح والطباعة
1. نزّل الملف المطلوب من هذا الفرع مع مجلد `../assets`.
2. افتح HTML في Chrome أو Edge أو Firefox حديث.
3. للطباعة اختر A4، الاتجاه العمودي، الهوامش الافتراضية للملف، وفَعّل طباعة الخلفيات.
4. اختر «حفظ بتنسيق PDF». راجع عدد الصفحات وفواصل الصفحات قبل مشاركة النسخة.

يجب إبقاء بنية المسارات كما هي لأن ملفات HTML تشير إلى الشعار في `../assets/logo.svg`.

## من يقرأ ماذا؟
- المستثمر أو الشريك في الاجتماع الأول: الملخص التنفيذي.
- المراجع التقني أو المالي أو القانوني: التقرير الكامل مع الوثيقة المصدرية وسجلات الأدلة.
- فريق المنتج: التقرير الكامل وخطة الإغلاق ومعايير القبول.

## حدود الإثبات
نجاح بناء التطبيق أو وجود كود لخدمة لا يثبت وحده تشغيلها في الإنتاج. أي ادعاء عن مستخدمين أو إيرادات أو شركاء أو امتثال أو جاهزية تشغيلية يجب أن يستند إلى دليل مؤرخ وقابل للتحقق. الأرقام التقديرية موسومة بوضوح ولا تمثل فواتير.
