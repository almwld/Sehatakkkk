# حزمة صحّتك الاستثمارية — ملفات HTML
## الإصدار المرجعي 1.4

هذه الحزمة مخصصة للمراجعة الاستثمارية والعناية التقنية، وتعرض منصة صحّتك على مستوى المنتج والوظائف والتقنيات والجاهزية.

## الملفات
- `executive-summary.html`: ملخص تنفيذي موجز للاجتماعات الأولى مع المستثمرين والشركاء.
- `report-full.html`: تقرير تفصيلي للمراجعة الفنية والتشغيلية والاستثمارية.

## المرجعية التقنية
- بيئة تطوير تطبيق Android: Android Studio.
- تقنيات التطبيق: Flutter وDart.
- الإصدار المرجعي للتوثيق الشامل: 1.4.

## الفتح والطباعة
1. افتح ملف HTML في إصدار حديث من Chrome أو Edge أو Firefox.
2. للطباعة اختر A4 والاتجاه العمودي، وفعّل طباعة الخلفيات.
3. اختر «حفظ بتنسيق PDF».
4. راجع فواصل الصفحات وتأكد من ظهور النص العربي والشعار بصورة صحيحة قبل المشاركة.

يجب إبقاء بنية مجلدات الحزمة كما هي لأن ملفات HTML تستخدم الأصول البصرية المرفقة.

## من يقرأ ماذا؟
- المستثمر أو الشريك في الاجتماع الأول: الملخص التنفيذي.
- المراجع التقني أو المالي أو القانوني: التقرير الكامل مع أدلة الاختبار والتشغيل والعقود.
- فريق المنتج: التقرير الكامل وخطة إغلاق المخاطر ومعايير القبول.

## حدود الإثبات
نجاح بناء التطبيق أو وجود وظيفة ضمن المنتج لا يثبت وحده تشغيلها في بيئة الإنتاج. وأي ادعاء عن مستخدمين أو إيرادات أو شركاء أو امتثال أو جاهزية تشغيلية يجب أن يستند إلى دليل مؤرخ وقابل للتحقق. الأرقام التقديرية لا تمثل فواتير أو إيرادات فعلية.

## الهوية البصرية
الألوان الأساسية: الأخضر `#0A8F83`، الأبيض `#FFFFFF`، الخلفية `#F4F6F7`، والنص `#263238`، مع واجهة عربية من اليمين إلى اليسار. يجب استخدام الشعار الأصلي الرسمي المعتمد دون إعادة رسمه أو استبداله بنسخة تقريبية. الأصول التجريبية المرفقة لا تُعتمد للنشر النهائي قبل مطابقتها مع الأصل الرسمي.
