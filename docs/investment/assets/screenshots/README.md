# لقطات شاشة المنتج

ضع هنا صوراً أصلية ملتقطة من إصدار محدد للتطبيق، بعد إزالة أي بيانات شخصية أو صحية حقيقية.

## اللقطات المطلوبة
1. الشاشة الرئيسية.
2. استعراض الأطباء أو تفاصيل الطبيب.
3. مسار الحجز (مع بيانات تجريبية).
4. الصيدلية وتفاصيل المنتج.
5. شاشة المكالمة قبل الاتصال وأثناءه، مع إخفاء معرفات المستخدمين.
6. الملف الصحي باستخدام حساب وبيانات اصطناعية فقط.

## تسمية الملفات
استخدم أسماء وصفية مثل `01-home.png` و`02-doctors.png`، وأرفق في وصف Pull Request رقم إصدار التطبيق والجهاز وتاريخ الالتقاط.

**لا ترفع** صور مرضى أو نتائج تحاليل أو أرقام هواتف أو محادثات حقيقية. هذا المجلد فارغ عمداً إلى أن يزوّد مالك المنتج بلقطات معتمدة؛ لا تُستخدم صور مولّدة على أنها لقطات من التطبيق.
